# Project icon

`ssh-service-runner.svg` is the editable source for the SSH Service Runner icon. A terminal window represents SSH command execution; the restart arrow represents the stop/start service workflow. The background outside the rounded tile is transparent.

- `ssh-service-runner.png`: 512 x 512 PNG for the README and other previews.
- `ssh-service-runner.ico`: Windows icon containing 16, 24, 32, 48, 64, 128, and 256 pixel sizes.

The PNG and ICO assets are exports of the SVG source.

To update the icon, edit the SVG and export a transparent 512 x 512 PNG with an SVG renderer. Export the PNG to the ICO sizes listed above. Image tooling is not a runtime dependency of this project.
